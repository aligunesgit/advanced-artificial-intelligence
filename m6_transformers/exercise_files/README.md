# M6 lab workspace

Follow the required lab in the [module](../README.md). This directory contains the assignment specification; starter implementations and solutions are not included.

Use this layout in your own submission repository:

```text
src/
configs/
results/
report.md
requirements.txt
README.md
```

Record the dataset source and license, split procedure, seeds, dependency versions, hardware, runtime, and exact run command. Keep raw data and large model weights out of version control. Include small generated results needed to assess the experiment.
