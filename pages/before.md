# Before the course

This is a graduate Artificial Intelligence course for students from different engineering disciplines. Begin with the [AI introductory sequence](../intro/what-is-ai.md), which establishes shared concepts before the technical modules. The checklist below describes preparation for the technical learning track; use it to identify review needs.

## Preparation checklist

- Manipulate matrix products, gradients, expectations, conditional probabilities, and Bayes’ rule.
- Explain maximum likelihood, overfitting, regularization, and train/validation/test separation.
- Implement a small gradient-based model in Python and interpret learning curves.
- Use Git, isolated Python environments, and a documented command-line workflow.

Diagnostic: derive logistic regression’s cross-entropy gradient, explain overfitting and distribution shift, and implement a leakage-free train/test pipeline. Revisit prerequisite material if these tasks are unfamiliar; the diagnostic is ungraded.

## Working environment

Use Python, NumPy, a plotting library, scikit-learn, and PyTorch as the course framework. Create an isolated environment and record exact installed versions in each submission. Install framework builds appropriate to your hardware using their official instructions. No paid API, dedicated GPU, or large-model training is required.

For each content week, complete the reading and derivation before class, discuss claims in the seminar, then complete the lab. Project work begins with a question and baseline before selecting additional methods.

## D2L preparation and environment

For the technical track, review selected material in D2L chapters 2–6, prioritizing tensors, automatic differentiation, regression, classification, MLPs, and module construction. Use [the official installation instructions](https://d2l.ai/chapter_installation/index.html) and select PyTorch in the book. D2L helper classes can differ from other tutorials; explain any helpers used in your submission. Record the book version or access date, Python version, PyTorch version, and d2l package version when applicable. Verify the selected notebook in your own environment before assigning or running a long experiment; notebook execution has not been validated as part of this curriculum preparation.
