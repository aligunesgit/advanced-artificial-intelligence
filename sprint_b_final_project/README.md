# Project Sprint B

Week 12 · Final experiments and project submission

1. Run the frozen protocol and document any justified changes.
2. Compare baseline and extension, including an ablation and uncertainty analysis.
3. Check that results and figures are traceable to configurations and run logs.
4. Reproduce one main result from a clean environment using documented commands.
5. Submit the report and reproducibility package, include the contribution statement.

The final report must distinguish measured findings from speculation. An inconclusive or negative result can earn full marks when the methodology and interpretation are sound.
